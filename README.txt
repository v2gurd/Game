NEON DRIVE ULTRA — WebGL prototype

Run:
- Upload index.html to GitHub Pages as the site's index.html.
- The page uses Three.js modules from jsDelivr and loads two real GLB assets at runtime:
  * Ferrari model: https://threejs.org/examples/models/gltf/ferrari.glb
  * Littlest Tokyo city scene: https://threejs.org/examples/models/gltf/LittlestTokyo.glb
- Internet access is required. Safari must allow WebGL.
- Controls: WASD / arrow keys, Space drift, Shift nitro; touch controls appear on phones.

Important scope note:
This is an asset-driven playable prototype, not a GTA V-scale production game. The Ferrari and city are genuine external GLB models. The road surface, lane markings, and traffic logic are generated by the game code. The city GLB is a stylized sample scene, not a photorealistic open-world city. For a full large city, add licensed modular GLB road/building packs (e.g. Kenney City Kit Roads / City Kit) into an assets folder and wire each model into the scene.
